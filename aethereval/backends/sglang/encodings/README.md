# Harmony tokenizer data

`o200k_base.tiktoken` is the official OpenAI tokenizer vocabulary used by the
Harmony parser embedded in the SGLang Model Gateway router. AetherEval ships it
so the router can start without network access.

Source: https://openaipublic.blob.core.windows.net/encodings/o200k_base.tiktoken
